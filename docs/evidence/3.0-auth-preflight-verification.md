### Arquivo: `.env.example` (atualizado)

Adicionada seção AUTH com 4 variáveis:
- `JWT_SECRET="SUA_CHAVE_JWT_AQUI"` — placeholder proibido
- `JWT_REFRESH_SECRET="SUA_CHAVE_REFRESH_AQUI"` — placeholder proibido
- `JWT_EXPIRES_IN="15m"` — access token 15 minutos
- `JWT_REFRESH_EXPIRES_IN="7d"` — refresh token 7 dias (alinhado com `REFRESH_TOKEN_EXPIRES_MS`)

Comentários explicam: usar `openssl rand -base64 48` para gerar segredos reais.

## Decisões técnicas

### 1. `FORBIDDEN_SECRETS` set com 8 placeholders conhecidos
```typescript
const FORBIDDEN_SECRETS = new Set([
  'SUA_CHAVE_AQUI', 'SUA_CHAVE_JWT_AQUI', 'SUA_CHAVE_REFRESH_AQUI',
  'changeme', 'secret', 'jwt_secret', 'your-secret-key', 'your-refresh-secret-key',
]);
```
Em runtime, se JWT_SECRET ou JWT_REFRESH_SECRET contiver qualquer um desses valores (case-insensitive), o startup falha. Evita deploy com valor default de exemplo.

### 2. Defaults efêmeros apenas em desenvolvimento
```typescript
jwtSecret = process.env.JWT_SECRET ?? generateEphemeralSecret();
```
Em produção: variáveis são OBRIGATÓRIAS. Em desenvolvimento: se não definidas, gera com `randomBytes(48).toString('base64')` = 64 chars (≥32 exigido em prod).

**Trade-off:** esses defaults mudam a cada restart — sessões não persistem entre restarts em dev. Para persistência, defina no `.env` local.

### 3. Carrega `.env` de múltiplos paths
```typescript
config({ path: ['../../.env', '../../../.env', '.env'] });
```
dotenv só carrega o PRIMEIRO arquivo que encontrar. Lista de paths:
- `../../.env` — quando rodando de `apps/api/` (cwd = `apps/api`)
- `../../../.env` — quando rodando de `apps/api/scripts/`
- `.env` — fallback (cwd atual)

### 4. `durationSchema` regex valida formato
```typescript
const durationSchema = z.string().regex(/^\d+\s*(ms|s|m|h|d|w|y)$/);
```
Aceita: "15m", "7d", "1h", "30ms", "1y". Rejeita: "15 dias", "7days", "".

### 5. JWT_SECRET ≠ JWT_REFRESH_SECRET (somente em produção)
Em produção, erro fatal se iguais — evita que atacante que roube um token possa forjar o outro. Em desenvolvimento, a validação é pulada (defaults efêmeros são sempre diferentes).
