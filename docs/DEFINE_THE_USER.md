# DEFINE_THE_USER.md — Quem usa o Almanaque dos Clubes

> Persona ≠ usuário logado: define expectativa, vocabulário e limite de promessa (T465 usa este
> arquivo como base da oferta honesta).

## 1. Visitante anônimo (Free)

- **Objetivo**: consultar clubes, jogadores, competições, campeões com fonte; navegar o mapa (futuro).
- **Expectativa**: dado auditável de graça, com proveniência; sem cadastro para ler.
- **Limite de promessa**: leitura + busca textual + exportação limitada. NADA de IA/predição.

## 2. Assinante Pro

- **Objetivo**: análise mais profunda (busca textual ampliada, exportação CSV) para conteúdo,
  jornalismo popular, pesquisa escolar/universitária inicial.
- **Expectativa**: o que o checkout lista — nada de IA operacional (está "em breve").

## 3. Assinante Elite

- **Objetivo**: conquistas auditáveis via Grafo do conhecimento, exportação CSV+JSON, volume maior.
- **Expectativa**: KG com fonte por aresta (hoje); API de dados futura ("em breve").

## 4. Contribuidor de correção (qualquer plano)

- **Objetivo**: apontar erro de dado com a fonte na mão (a proveniência expõe o link).
- **Canal**: /metodologia + canais de privacidade/contato.

## 5. Operador/END ART (interno — dono do produto)

- Identidade legal, DPO, contratos, preço, domínio. NÃO é usuário do produto: é o responsável
  pelos gates jurídico/financeiro ([docs/COMPLIANCE.md](./COMPLIANCE.md)).

## 6. Agente autônomo (Doer/Thinker) — interno

- Executa/planeja com as regras de [RULES.md](./RULES.md). O "usuário" dos documentos de estado
  é ele — por isso R3 existe: docs de estado mentem se não forem re-ancorados.

## Anti-persona (o que NÃO somos hoje)

Não somos fonte de apostas/probabilidades, não temos dados em tempo real, não temos cobertura
completa de divisões inferiores — e a oferta NUNCA deve sugerir o contrário (CDC art. 30/37).
